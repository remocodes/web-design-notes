مذكرة تأسيسية في تصميم مواقع الويب

أساسيات HTML وCSS للمبتدئين

إعداد: Reem Ahmed
مقدمة أساسيات HTML أساسيات CSS تطبيق عملي أسئلة للمراجعة

مقدمة

تصميم مواقع الويب بيعتمد على مجموعة من اللغات، وكل لغة ليها وظيفة مختلفة في بناء الموقع.

  • HTML: بتحدد محتوى الصفحة وعناصرها الأساسية.
  • CSS: بتحدد شكل العناصر وتنسيقها والألوان والخلفيات.
  • JavaScript: بتضيف التفاعل والحركة والوظائف للصفحة.
معلومة مهمة: HTML مسؤولة عن هيكل الصفحة، وCSS مسؤولة عن مظهرها.

الفصل الأول: أساسيات HTML

1. الهيكل الأساسي لصفحة HTML

كل صفحة ويب بتحتاج هيكل أساسي بنكتب داخله المحتوى اللي هيظهر للمستخدم. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>موقعي الأول</title>
</head>
<body>
    <h1>أهلًا بكم</h1>
    <p>دي أول صفحة ويب ليا.</p>
</body>
</html>
  • <html>: العنصر الرئيسي للصفحة.
  • <head>: معلومات وإعدادات الصفحة.
  • <title>: عنوان الصفحة في تبويب المتصفح.
  • <body>: المحتوى الظاهر للمستخدم.
  • lang="en": يستخدم لتحديد اللغة لمحتوي صفحة الويب,وفي هذه الحالة يعني ان الصفحة هي انجليزي.

2. العناوين Headings

بنستخدم العناوين لتنظيم محتوى الصفحة من العنوان الرئيسي للعناوين الفرعية.

<h1>عنوان رئيسي</h1>
<h2>عنوان فرعي</h2>
<h3>عنوان أصغر</h3>

عناصر العناوين بتبدأ من <h1> لحد <h6>.

3. الفقرات Paragraphs

<p>أهلًا بكم في موقع المعهد.</p>

العنصر <p> بيستخدم لكتابة فقرة نصية.

4. تنسيق النصوص

<strong>نص مهم</strong>
<em>نص للتأكيد</em>
<mark>نص مميز</mark>
  • strong: لتوضيح أهمية النص.
  • em: للتأكيد على النص.
  • mark: لتمييز النص.

5. الروابط Links

<a href="https://www.google.com">
    افتح جوجل
</a>

العنصر <a> بيعمل رابط، والخاصية href بتحدد المكان اللي الرابط هيفتحه.

6. إضافة الصور Images

<img src="logo.png"
     alt="شعار المعهد"
     width="200">
  • src: مسار الصورة.
  • alt: وصف بديل للصورة.
  • width: عرض الصورة.
لازم تكون الصورة موجودة في المسار المكتوب داخل src.

7. القوائم Lists

قائمة غير مرتبة:

<ul>
    <li>تكنولوجيا المعلومات</li>
    <li>نظم المعلومات</li>
    <li>علوم الحاسب</li>
</ul>

قائمة مرتبة بالأرقام:

<ol>
    <li>تعلم HTML</li>
    <li>تعلم CSS</li>
    <li>تعلم JavaScript</li>
</ol>

<ul> قائمة غير مرتبة، و<ol> قائمة مرتبة، و<li> عنصر داخل القائمة.

8. إنشاء زر Button

<button>اعرف المزيد</button>

بيعمل زرًا في الصفحة، لكن إضافة وظيفة للزر ممكن تحتاج JavaScript.

9. إنشاء جدول Table

<table>
    <tr>
        <th>القسم</th>
        <th>عدد الطلاب</th>
    </tr>
    <tr>
        <td>تكنولوجيا المعلومات</td>
        <td>100</td>
    </tr>
</table>
  • table: إنشاء الجدول.
  • tr: إنشاء صف.
  • th: خلية عنوان.
  • td: خلية بيانات.

10. نموذج إدخال البيانات Form

<form>
    <label for="name">الاسم:</label>
    <input type="text" id="name" name="name">
    <button type="submit">إرسال</button>
</form>

النموذج بيسمح للمستخدم بإدخال بيانات. أما حفظها في قاعدة بيانات، فبيحتاج برمجة إضافية مثل PHP وقاعدة بيانات.

الفصل الثاني: أساسيات CSS

1. ربط CSS بصفحة HTML

بنكتب السطر التالي داخل عنصر <head> في ملف HTML: 

<link rel="stylesheet" href="style.css">

السطر ده بيربط صفحة HTML بملف التنسيق اللي اسمه style.css وهو مهم جداا.

2. شكل كود CSS

p {
    color: blue;
    font-size: 18px;
}
  • p: العنصر اللي هيتم استدعاءة من الHTML.
  • color: خاصية لون النص.
  • blue: قيمة اللون.
  • font-size: خاصية حجم الخط.
  • 18px: قيمة حجم الخط.

3. تغيير لون النص

h1 {
    color: purple;
}

الكود بيخلي لون العنوان بنفسجي.

4. تغيير لون الخلفية

body {
    background-color: #F5F0FF;
}

الكود بيغير لون خلفية الصفحة كلها.

5. تغيير حجم الخط ونوعه

body {
    font-family: Arial, sans-serif;
}

p {
    font-size: 16px;
}

font-family بتحدد نوع الخط، وfont-size بتحدد حجمه.

6. محاذاة النص

h1 {
    text-align: center;
}

القيمة center بتخلي النص في المنتصف.

7. المسافات الداخلية والخارجية

.card {
    padding: 20px;
    margin: 20px;
}
  • padding: مساحة داخل العنصر بين المحتوى وحدوده.
  • margin: مساحة خارج العنصر بينه وبين العناصر الأخرى.

8. الحدود والزوايا

.card {
    border: 1px solid #CCCCCC;
    border-radius: 12px;
}

border بتضيف حدودًا للعنصر، وborder-radius بتخلي زواياه دائرية.

9. استخدام Class

في HTML:

<p class="special">أهلًا بكم</p>

في CSS:

.special {
    color: purple;
    font-weight: bold;
}

بنستخدم النقطة قبل اسم class في CSS، عشان ننسق العناصر اللي تحمل الاسم ده.

10. استخدام ID

<h1 id="main-title">معهد التكنولوجيا</h1>
#main-title {
    color: darkblue;
}

بنستخدم علامة # قبل اسم id في CSS. والأفضل إن كل ID يكون فريدًا داخل الصفحة.

11. ترتيب العناصر باستخدام Flexbox

.container {
    display: flex;
    gap: 20px;
    justify-content: center;
}
  • display: flex: لترتيب العناصر باستخدام Flexbox.
  • gap: لتحديد المسافة بين العناصر.
  • justify-content: للتحكم في توزيع العناصر على المحور الرئيسي.

12. تغيير شكل الزر عند المرور عليه

button:hover {
    background-color: darkblue;
}

الكود بيغير لون خلفية الزر لما مؤشر الفأرة يمر فوقه.

الفصل الثالث: تطبيق عملي

دلوقتي هنجمع HTML وCSS في مثال بسيط لموقع معهد تكنولوجي.

كود HTML

<header>
    <h1>معهد التكنولوجيا</h1>
    <p>نحو مستقبل رقمي أفضل</p>
</header>

<main>
    <h2>أهلًا بكم في موقع المعهد</h2>
    <p>اكتشفوا الأقسام المتاحة لدينا.</p>

    <div class="card">
        <h3>تكنولوجيا المعلومات</h3>
        <p>تعلم البرمجة وتطوير المواقع.</p>
        <button>اعرف المزيد</button>
    </div>
</main>

كود CSS

body {
    font-family: Arial, sans-serif;
    background-color: #F5F0FF;
    text-align: center;
    margin: 0;
}

header {
    background-color: #5B2C83;
    color: white;
    padding: 30px;
}

main {
    padding: 30px 20px;
}
 .card {
    background-color: white;
    padding: 20px;
    margin: 20px auto;
    max-width: 400px;
    border-radius: 12px;
}

button {
    background-color: #5B2C83;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 8px;
    cursor: pointer;
}
طريقة التشغيل: احفظي أكواد HTML في ملف index.html، وأكواد CSS في ملف style.css داخل نفس المجلد. افتحي index.html في المتصفح لمشاهدة النتيجة.
